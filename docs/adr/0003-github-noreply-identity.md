# Commits use the owner's GitHub noreply identity

The first history rewrite gave every commit a placeholder author named `Contributor`, with the address GitHub reserves for the login `contributor` at its noreply domain. GitHub reads such an address as the private email of the account with that login, so it credited every commit to an unrelated account named `contributor`, and none counted toward the owner's contributions. We rewrote the history again so every commit uses the owner's login and ID-based noreply address (`REPO_NAME` and `REPO_EMAIL` in `scripts/check_privacy.py`). The real email stays private and the commits count for the owner, at the cost of showing the owner's public login on every commit, new commit IDs, and a second force push. Any placeholder address at GitHub's noreply domain can belong to someone, so the identity must be one the owner controls.
