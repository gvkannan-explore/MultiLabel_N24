Zero-Shot LLM Scoring with vLLM

Why · 2 requests Create a plan to evaluate a simple LLM (say <1B but comparable to RoBERta, ModernBERT and UltraBERT) using VLLM. To clarify what we're trying to do is to just compare the out of zero shot classification performance of these LLMs without any training.

A user can score an LLM zero-shot on the test split with one command.

Two models Qwen/Qwen3-0.6B, with thinking mode off, and HuggingFaceTB/SmolLM2-360M-Instruct. Neither model is gated, so no Hugging Face token is necessary.

The prompt gives the 24 sections and the abstract, and asks for one section.

Which part of the article does the LLM read?

vLLM can only answer with one of the 24 section names.

Version The name of the structured output API changed between vLLM releases. Make sure that the sketch agrees with the vLLM version that the lock file pins.

How does the LLM pick a section?

A Modal function runs vLLM and gives the predictions to the laptop.

The test split goes to Modal as a list of chats. The n24-data volume stays as it is.

Zero-shot results use the same ruler as the encoder results.

EVAL_VERSION stays 1, because the test split and the metrics do not change.

ADR 0005 asks for a bump only when scores can move.

Two passes with fresh loads must give the same section for each article.

Risk vLLM on a GPU is not bit-exact across batches. Greedy choices can differ for a small number of articles. The results file records the count. It does not hide it.

Shared: vLLM installs only in the Modal image.

Risk On macOS, pyright cannot resolve import vllm. Keep the import in src/eval/zero_shot.py only, with one # pyright: ignore[reportMissingImports].

Not changing: training, the deployment gate, the inference API.

  • Two models only: Qwen3-0.6B and SmolLM2-360M-Instruct. No gated models such as Llama.
  • No comparison table. Each results file prints its own scores.
  • No fine-tuning. src/train/ does not change.
  • src/gate/report.py and gate/criteria.toml do not change.
  • No few-shot prompts and no prompt tuning on the test split.
  • The encoder runs (RoBERTa, ModernBERT) come from the trainer as before. This plan does not train them.
  • CI does not run vLLM. Unit tests use a fake predict; a Modal smoke run with --limit 50 tests vLLM.
